# Architecture Decision Records (ADRs)

This section contains Architecture Decision Records (ADRs) that document significant architectural decisions made for the Lighthouse project.

## What is an ADR?

An ADR is a document that describes an architectural decision, its context, consequences, and alternatives considered. ADRs help future developers understand *why* certain technical choices were made.

## Quick Start

- **Document a new decision?** Copy an existing ADR and update
- **Understand a choice?** Read the relevant ADR below
